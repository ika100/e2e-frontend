## 🚀 What's New in v0.1.3

### Highlights
This patch release focuses on CI/CD pipeline reliability and security hygiene improvements. The npm audit step has been tightened to scan production dependencies only, eliminating false-positive DoS alerts from dev tooling. Several CI tooling updates — including a Trivy scan fix, an optional Gitleaks step, and a Devbox action upgrade — make the pipeline more robust across environments.

### 🔒 Security
- npm dependency audit now targets production dependencies only (`--omit=dev`), preventing dev-only packages (e.g. Vite, esbuild) from generating misleading DoS false positives in CI security checks.
