# Release v0.1.0 — Frontend SPA

## What's New

This is the **first release** of the `frontend` service for the e2e-platform. It delivers a
fully functional React + Vite + TypeScript SPA served by an nginx:alpine Docker container.

## Features

### 🎉 Greeting Widget
Enter a name and click "Get Greeting" (or press Enter) to fetch a personalised greeting
from `greeting-service`. Displays loading state, success greeting, and inline errors.

### 🔢 Counter Widget
Enter a counter name and click **Read** to see the current value or **Increment** to
increase it by one. Client-side validation prevents invalid names from ever reaching the
backend. Handles 404 (counter not yet created), 429 (rate limit), and 5xx gracefully.

### 🏗 App Shell
- Client-side routing via `wouter` — `/` (Greeting) and `/counter` (Counter)
- Error boundary — blank page replaced with a friendly error + Reload button
- Accessible header with active navigation link highlighting
- Responsive layout — works from 320px mobile to 1440px desktop

### 🛡 Security
- Content Security Policy with `connect-src` scoped to configured service URLs
- `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`
- Runs as non-root (UID 1001) in the container
- Zero production dependency CVEs (`npm audit --audit-level=high --omit=dev`)
- React's JSX escaping protects against XSS from API responses

### ⚙ CI/CD
- GitHub Actions: `security` → `test` → `build` → `release` → `gitops-update`
- Docker image: `ghcr.io/ika100/e2e-frontend:0.1.0` and `:latest`

## Docker

```bash
  -e VITE_COUNTER_SERVICE_URL=https://counter.example.com \
  ghcr.io/ika100/e2e-frontend:0.1.0
```
